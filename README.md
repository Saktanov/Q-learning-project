Q-Learning Coin Hunter AI

Данный проект представляет собой RL-симулятор поиска монет с использованием алгоритма Q-learning. AI-агент обучается самостоятельно перемещаться по Grid World (сетке), избегать препятствий, находить монеты и выбирать наиболее эффективный маршрут для получения максимальной награды. Проект включает обучение агента, визуализацию среды, отображение стратегии AI и интерактивный веб-интерфейс на Streamlit.

Цель проекта — продемонстрировать работу reinforcement learning на простой игровой среде, где агент обучается искать кратчайший путь к монете, избегать препятствий, минимизировать количество шагов, принимать оптимальные решения и максимизировать rewards.

Для запуска проекта необходимо:

pip install -r requirements.txt
streamlit run app.py

После запуска откроется веб-приложение, где можно:

обучать AI-агента
наблюдать за обучением в реальном времени
просматривать графики rewards
запускать симуляцию обученного агента
анализировать поведение модели
